# ls-3

Практические задания по системному программированию (урок 3) на C#: запуск внешних процессов.

## Содержимое

| Папка | Тема |
| --- | --- |
| `Practice1_ProcessManager` | Диспетчер, который запускает утилиту и сообщает, как она завершилась |
| `Practice2_ProcessOutput` | Раздельный сбор stdout и stderr запущенного процесса |

В каждой папке лежит описание задания в `README.md`.
